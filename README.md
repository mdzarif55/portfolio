# Md. Muhtasim Zarif — Modern Developer Portfolio

A modern, high-performance developer portfolio built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed specifically for **Md. Muhtasim Zarif** — MERN Stack & Cross-Platform Developer based in Dhaka, Bangladesh.

Featuring **Light & Dark mode** with zero hydration flash, interactive live project previews, competitive programming achievements, academic background, and an integrated resume PDF viewer with direct download.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 14 (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Theme Provider**: [`next-themes`](https://github.com/pacocoursey/next-themes)
- **Icons**: [`lucide-react`](https://lucide.dev/)
- **Animations & Effects**: [`canvas-confetti`](https://www.npmjs.com/package/canvas-confetti)
- **Deployment Ready**: Optimized for [Vercel](https://vercel.com)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
